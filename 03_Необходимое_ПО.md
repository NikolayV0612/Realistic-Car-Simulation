# Необходимое программное обеспечение

## Обязательный стек

| Категория            | Программа                        | Назначение                              |
|----------------------|----------------------------------|-----------------------------------------|
| Игровой движок       | Unreal Engine 5.4+              | Основная разработка                     |
| 3D-моделирование     | Blender 4.x                     | Модели, риг, UV, анимации               |
| Текстуры и материалы | Substance 3D Painter + Designer | PBR-материалы                           |
| Контроль версий      | Git + Git LFS (или Perforce)    | Хранение проекта и ассетов              |
| IDE                  | Visual Studio 2022 / Rider      | C++ и отладка                           |
| Звук                 | Wwise или MetaSounds            | Двигатель, шины, двери, окружение       |
| 2D / UI              | Figma + Photoshop / Affinity    | Мокапы панелей, иконки                  |
| Документация         | Markdown (Obsidian / VS Code)   | Документы проекта                       |
| Таблицы данных       | Excel / Google Sheets           | Vehicle DataTable, балансировка         |
